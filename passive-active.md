# Reconnaissance: Passive vs Active

Reconnaissance is information gathering performed before a security assessment.

## Passive reconnaissance
Uses information already publicly available and avoids directly probing the target's infrastructure. Examples:
- Reading a public organisation website and its published technical documentation.
- Reviewing public DNS records.
- Checking public domain registration information where available.

## Active reconnaissance
Interacts directly with an authorised target. Examples:
- Discovering services on a lab host.
- Checking which ports are open on a system in the agreed scope.
- Mapping routes and endpoints of a local test application.

## Comparison

| Passive | Active |
|---|---|
| Uses public/third-party information sources | Sends traffic to the target |
| Usually lower chance of alerting target systems | May be logged or detected |
| Does not establish that a service is reachable | Can identify reachable services |
| Still requires ethical and legal handling | Requires explicit authorisation and defined scope |
