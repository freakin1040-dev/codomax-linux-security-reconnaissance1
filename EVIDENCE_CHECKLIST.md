# Evidence Checklist

Only tick an item after personally running it and saving the evidence.

- [x] Ubuntu/WSL installed (confirmed by learner)
- [x] `pwd`, `ls`, `whoami`, `mkdir`, `cd`, `touch`, `ls -l`, `id` demonstrated in supplied terminal screenshot
- [ ] `chmod 755` run and resulting permissions captured
- [ ] `groups`, `ps`, `top`, and `sudo whoami` run and documented
- [ ] Local training app starts at `127.0.0.1:8000`
- [ ] Nmap version and local-only scan output saved
- [ ] Wireshark localhost capture saved and inspected
- [ ] Burp request/response screenshot saved (secrets removed)
- [ ] OWASP ZAP scan report/screenshot saved
- [ ] REPORT.md completed with actual observations
- [ ] All screenshots reviewed for passwords, tokens, cookies, and personal data

Recommended evidence folders:
- `evidence/linux/`
- `evidence/nmap/`
- `evidence/wireshark/`
- `evidence/burp/`
- `evidence/zap/`
